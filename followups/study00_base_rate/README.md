# Base rate (baserate.py)
Lexical classifier estimating how often benign requests contain an ungroundable
external entity. **No API calls** — pure classification, calibrated against
Study 1's 101 prompts (ground truth: prompt #65 was the only decoy-firing one).
Harness: `harness/baserate.py`  ·  Corpus: `data/corpora.json`
